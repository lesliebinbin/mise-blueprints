#+title: Emacs Lisp Copier Template

This branch is a standalone Copier template for a mise-managed Emacs Lisp
package using Eldev.

* Generate a package

Use this branch directly from GitHub and answer the template questions:

#+begin_src shell
copier copy \
  --vcs-ref emacs-lisp/v0.0.1 \
  git@github.com:lesliebinbin/mise-blueprints.git \
  ./my-emacs-package
#+end_src

Use =--defaults= to accept every default answer non-interactively:

#+begin_src shell
copier copy \
  --defaults \
  --vcs-ref emacs-lisp/v0.0.1 \
  git@github.com:lesliebinbin/mise-blueprints.git \
  ./my-emacs-package
#+end_src

* Pinning the template

=--vcs-ref= accepts one Git branch, tag, or commit SHA. For repeatable
automation, use an immutable tag or full commit SHA after the branch is
finalized:

#+begin_src shell
copier copy \
  --vcs-ref <tag-or-full-commit-sha> \
  git@github.com:lesliebinbin/mise-blueprints.git \
  ./my-emacs-package
#+end_src

* Local development

Render the template with its complete example answers:

#+begin_src shell
copier copy \
  --data-file answers.yml.example \
  . \
  /tmp/example-emacs-package
#+end_src

* Generated package setup

#+begin_src shell
cd my-emacs-package
mise install
mise setup
mise check
#+end_src
