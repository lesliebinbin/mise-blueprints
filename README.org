#+title: uv OpenUSD Copier Template

This branch is a standalone Copier template for a mise- and uv-managed OpenUSD
project.

* Generate a project

#+begin_src shell
copier copy \
  --vcs-ref uv-openusd/v0.0.1 \
  git@github.com:lesliebinbin/mise-blueprints.git \
  ./my-openusd-project
#+end_src

Use =--defaults= to accept every default answer non-interactively:

#+begin_src shell
copier copy \
  --defaults \
  --vcs-ref uv-openusd/v0.0.1 \
  git@github.com:lesliebinbin/mise-blueprints.git \
  ./my-openusd-project
#+end_src

* Pinning the template

=--vcs-ref= accepts one Git branch, tag, or commit SHA. For repeatable
automation, use an immutable tag or full commit SHA after the branch is
finalized:

#+begin_src shell
copier copy \
  --vcs-ref <tag-or-full-commit-sha> \
  git@github.com:lesliebinbin/mise-blueprints.git \
  ./my-openusd-project
#+end_src

* Local development

#+begin_src shell
copier copy \
  --data-file answers.yml.example \
  . \
  /tmp/example-openusd-project
#+end_src

* Generated project setup

#+begin_src shell
cd my-openusd-project
mise install
mise setup
mise build
mise check
mise exec -- uv run python
#+end_src

In Python, enable the locally built bindings before importing USD:

#+begin_src python
import openusd
from pxr import Usd
#+end_src

Run from the project directory so Python can find =openusd=. No =PYTHONPATH=
setting is needed. Mise adds =openusd/bin= to =PATH= for command-line tools.
The build copies =openusd-init.py= into =openusd/__init__.py= and retains the
bootstrap source. It stops on failure and only removes =openusd-temp= after
successful installation. To build again, run =mise setup= and =mise build=.
