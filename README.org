#+title: Mise Blueprints

This repository is an index of standalone, versioned Copier templates. Select
one published branch; =master= is documentation only and is not a template.

| Blueprint | Branch |
|-----------+--------|
| uv Python | =uv-python/v0.0.1= |
| React | =react/v0.0.1= |
| Emacs Lisp | =emacs-lisp/v0.0.1= |
| PyTorch CUDA extension | =pytorch-ext/v0.0.1= |

* Generate with defaults

#+begin_src shell
copier copy --defaults \
  --vcs-ref react/v0.0.1 \
  https://github.com/lesliebinbin/mise-blueprints.git \
  ./my-react-app
#+end_src

* Generate with an answers file

Create a local answers file, for example =answers.yml=:

#+begin_src yaml
project_name: My React App
project_slug: my-react-app
description: My mise-managed React application
node_version: "24"
#+end_src

Then pass it to Copier:

#+begin_src shell
copier copy --data-file answers.yml \
  --vcs-ref react/v0.0.1 \
  https://github.com/lesliebinbin/mise-blueprints.git \
  ./my-react-app
#+end_src
