#+title: PyTorch CUDA Extension Copier Template

This branch is a standalone Copier template for a mise- and uv-managed
PyTorch CUDA extension project. It includes CUDA matrix-multiplication learning
examples and generates a machine-local =.clangd= configuration from the
installed PyTorch include and library paths.

* Generate a project

Use this branch directly from GitHub and answer the template questions:

#+begin_src shell
copier copy \
  --vcs-ref pytorch-ext/v0.0.1 \
  gh:lesliebinbin/mise-blueprints \
  ./my-pytorch-extension
#+end_src

Use =--defaults= to accept every default answer non-interactively:

#+begin_src shell
copier copy \
  --defaults \
  --vcs-ref pytorch-ext/v0.0.1 \
  gh:lesliebinbin/mise-blueprints \
  ./my-pytorch-extension
#+end_src

* Pinning the template

=--vcs-ref= accepts one Git branch, tag, or commit SHA. The branch above is
convenient during development. For repeatable automation, use an immutable tag
or full commit SHA after the branch is finalized:

#+begin_src shell
copier copy \
  --vcs-ref <tag-or-full-commit-sha> \
  gh:lesliebinbin/mise-blueprints \
  ./my-pytorch-extension
#+end_src

* Local development

Render the template with its complete example answers:

#+begin_src shell
copier copy \
  --data-file answers.yml.example \
  . \
  /tmp/example-pytorch-extension
#+end_src

* Generated project setup

#+begin_src shell
cd my-pytorch-extension
mise install
mise setup
uv run python main.py
#+end_src

=mise setup= synchronizes dependencies and writes =.clangd=. Running =main.py=
requires a CUDA-capable PyTorch installation and a compatible NVIDIA system.
