#+title: uv OpenUSD Copier Template

This branch is a standalone Copier template for a mise- and uv-managed OpenUSD
project.

* Generate a project

#+begin_src shell
copier copy \
  --vcs-ref uv-openusd/v0.0.2 \
  git@github.com:lesliebinbin/mise-blueprints.git \
  ./my-openusd-project
#+end_src

Use =--defaults= to accept every default answer non-interactively:

#+begin_src shell
copier copy \
  --defaults \
  --vcs-ref uv-openusd/v0.0.2 \
  git@github.com:lesliebinbin/mise-blueprints.git \
  ./my-openusd-project
#+end_src

* Pinning the template

=--vcs-ref= accepts one Git branch, tag, or commit SHA. For repeatable
automation, use an immutable tag or full commit SHA after the branch is
finalized:

#+begin_src shell
copier copy \
  --vcs-ref <tag-or-full-commit-sha> \
  git@github.com:lesliebinbin/mise-blueprints.git \
  ./my-openusd-project
#+end_src

* Local development

#+begin_src shell
copier copy \
  --data-file answers.yml.example \
  . \
  /tmp/example-openusd-project
#+end_src

* Generated project setup

#+begin_src shell
cd my-openusd-project
mise install
mise setup
mise build
mise check
mise exec -- uv run python
#+end_src

The locally built bindings are available directly from the generated project's
virtual environment:

#+begin_src python
from pxr import Usd
#+end_src

The build writes =openusd-bindings.pth= into the generated project's virtual
environment, so Python, editors, and language servers using that environment
can find =pxr= without =PYTHONPATH= or a bootstrap import. Mise also adds
=openusd/build/bin= to =PATH= for command-line tools. To build again, run
=mise setup= and =mise build=.
