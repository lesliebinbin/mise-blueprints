#+title: Emacs C++20 Native Module Copier Template

This branch is a standalone Copier template for a mise-managed Emacs native
module ("dynamic module") written in C++20 and built with CMake.  Generated
projects contain a small but complete module source plus the CMake glue needed
to compile it against =emacs-module.h=; the result is a shared library (a
=.so= on GNU/Linux) that you load into Emacs yourself with =module-load= and
wrap however you like.

* Generate a module

Use this branch directly from GitHub and answer the template questions:

#+begin_src shell
copier copy \
  --vcs-ref emacs-ext/v0.0.1 \
  https://github.com/lesliebinbin/mise-blueprints.git \
  ./my-emacs-module
#+end_src

Use =--defaults= to accept every default answer non-interactively:

#+begin_src shell
copier copy \
  --defaults \
  --vcs-ref emacs-ext/v0.0.1 \
  https://github.com/lesliebinbin/mise-blueprints.git \
  ./my-emacs-module
#+end_src

* Pinning the template

=--vcs-ref= accepts one Git branch, tag, or commit SHA. For repeatable
automation, use an immutable tag or full commit SHA after the branch is
finalized:

#+begin_src shell
copier copy \
  --vcs-ref <tag-or-full-commit-sha> \
  https://github.com/lesliebinbin/mise-blueprints.git \
  ./my-emacs-module
#+end_src

* Local development

Render the template with its complete example answers:

#+begin_src shell
copier copy \
  --data-file answers.yml.example \
  . \
  /tmp/example-emacs-module
#+end_src

* Generated project setup

#+begin_src shell
cd my-emacs-module
mise install
mise build
mise check
#+end_src

=mise build= configures and compiles the module into =build/=, producing
=build/libmy-emacs-module.so=; =mise check= additionally loads the compiled
module in Emacs batch mode and calls one of its functions as a smoke test.

If you drive CMake directly instead of mise, the bundled =CMakePresets.json=
reproduces the same configuration (build directory =build/=, Debug build
type) without typing the flags:

#+begin_src shell
cmake --list-presets          # list available presets
cmake --preset default        # configure into build/
cmake --build --preset default  # compile into build/libmy-emacs-module.so
#+end_src

Presets require CMake 3.21 or newer; the plain =cmake -S . -B build=
commands inside =mise.toml= keep working on older CMake.  Both entry points
write to the same =build/= directory.

External prerequisites, not managed by mise: an Emacs with native module
support and the matching =emacs-module.h= header (typically installed
alongside Emacs at =/usr/local/include= or =/usr/include=), CMake 3.16 or
newer, and a C++20 compiler.  If your Emacs installs headers elsewhere, point
CMake at them with =cmake -DEMACS_MODULE_INCLUDE_DIR=/path/to/include=.
